# Install and open Optimize Bar

The supplied 1.0.0 release is a **Win64 source plugin for Unreal Engine 5.8.0**. Use an installed, supported Unreal Engine version and the C++ build tools required by that engine. The package is not a set of precompiled editor binaries for every engine version.

## Dependencies and needed plugins

Optimize Bar requires these two Unreal Engine plugins:

1. `MovieRenderPipeline` (Movie Render Pipeline)
2. `ImpostorBaker` (Impostor Baker)

Confirm that both are available and enabled for the project. If Unreal Editor asks to enable either dependency when you enable Optimize Bar, accept the prompt and restart the Editor.

## Place the plugin in the project

<Tabs>
  <TabItem value="new" label="Fresh installation" default>

1. Close Unreal Editor.
2. Back up the project.
3. Extract the supplied package into the project's `Plugins` folder. The file must end up at `Plugins/VPOptimizationTools/VPOptimizationTools.uplugin`.
4. Open the project and allow its compatible C++ build if needed.

  </TabItem>
  <TabItem value="replace" label="Replacing an installation">

1. Close Unreal Editor before replacing plugin files.
2. Back up both the project and its existing `Plugins/VPOptimizationTools` folder.
3. Replace that folder with the supplied release. Check that `VPOptimizationTools.uplugin` is directly inside `Plugins/VPOptimizationTools`.
4. Reopen the project and complete any required build.

  </TabItem>
</Tabs>

Enable **Optimize Bar** if Unreal asks, and restart the Editor when prompted.

Open **Optimize Bar** from its Unreal Editor toolbar entry. If it does not appear, verify the folder path, engine version, build tools, plugin enablement, and any restart request before trying again.

## Choose the working mode

Select **ICVFX / Virtual Production**, **Cinematic Rendering**, or **Game**. The main navigation then presents **Audit Capture**, **Scene Optimization**, and **Fixes**. Set up the relevant camera and scene scope for the mode before collecting evidence.
